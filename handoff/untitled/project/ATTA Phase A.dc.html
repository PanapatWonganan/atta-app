Line-breaking rule
Affirmations are hand-broken, not auto-wrapped. Each line is authored as a phrase, capped at 34 Latin characters, and stored with its breaks. Two to three lines per card; never a single orphan word on line three.
For a Thai release, break on word boundaries via ICU BreakIterator, then hand-correct. Never rely on the default character wrap — it splits vowel clusters.

Text position, all themes
Eyebrow baseline 34dp from top, left inset 28dp. Affirmation block bottom-aligned to 52dp from bottom. Date baseline 26dp from bottom, left inset 28dp. Right inset 28dp; text column max 268dp.
Bitmap sizes @4x
2×2 — 158×158dp → 632×632 px
4×2 — 330×158dp → 1320×632 px
4×4 — 330×330dp → 1320×1320 px
Draw at 4x, downscale in Glance. Budget ≤ 1.8 MB per RemoteViews transaction.
Luminance spread
Every theme keeps its two end stops within 0.35 absolute relative luminance (WCAG L, 0–1 scale), so the affirmation holds effectively the same contrast at the top of the card as at the bottom. Ratios above are measured against the worst stop, not the average, and are truncated rather than rounded.

05
Notes for the build
Widget is one bitmap
Render the gradient, hairline and text on a Canvas in a worker, cache the PNG per theme + date, hand Glance an ImageProvider. Re-render only when the affirmation or theme changes, not on every update tick.
Text is baked, so measure it yourself
Use StaticLayout with the authored line breaks and an explicit lineSpacingMultiplier of 1.6. Do not let the system auto-size — it will pick a value that clips tone marks once Thai lands.
Blur fallback
In-app blur is decoration only. Below API 31 substitute a flat canvasAlt fill at 92% opacity. Nothing in the layout should depend on seeing through it.
Touch targets
Save, share and theme controls are 48×48dp minimum with 8dp between them, even where the visible icon is 24dp. The widget itself has one tap target: the whole surface, opening today's card.
Open before Phase B
Your 15 affirmation lines, so the mockups stop carrying placeholder copy. A tagline for ATTA. The ten category names, which decide how the five accents get assigned. Once those land I will take Phase A into the 2×2 and 4×4 sizes, then move to the widget gallery and the home card.
