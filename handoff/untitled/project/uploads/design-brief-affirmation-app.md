# Design Brief — แอป Daily Affirmation (Android)
### สำหรับส่งให้ Claude Design

> **วิธีใช้:** วางเอกสารนี้ทั้งฉบับลงใน Claude Design แล้วเริ่มจากส่วนที่ 8 (ลำดับงาน) ก่อนอย่าเพิ่งขอทุกหน้าจอพร้อมกัน ให้ทำทีละเฟส แล้วรีวิวก่อนไปต่อ

---

## 1. โจทย์โดยย่อ

ออกแบบ visual identity และ UI ทั้งหมดของแอป affirmation รายวันบน Android ที่มี **home screen widget เป็นสินค้าหลัก** ไม่ใช่ฟีเจอร์เสริม

สิ่งที่ผู้ใช้ซื้อจริงๆ คือ **"หน้าจอมือถือของฉันจะสวยขึ้น และฉันจะรู้สึกดีขึ้นทุกครั้งที่มอง"** ไม่ใช่คลังคำคม ดังนั้นน้ำหนักของงานออกแบบต้องเทไปที่ widget และการ์ด affirmation มากกว่าหน้าจอ setting

**แพลตฟอร์ม:** Android เท่านั้น (Jetpack Compose + Glance)
**ภาษา:** ไทย เป็นหลัก / อังกฤษ เป็นรอง — ทุกดีไซน์ต้องเทสต์ด้วยข้อความไทยจริง
**ชื่อแอป:** `[ใส่ชื่อ]`

---

## 2. Positioning และโทน

**Wellness luxury** — ความหรูแบบสปาชั้นดี ไม่ใช่ความหรูแบบทองคำเพชรพลอย

จุดอ้างอิงทางความรู้สึก:
- ล็อบบี้ resort เงียบๆ ตอนเช้าตรู่ แสงธรรมชาติ ผ้าลินิน หินขัด
- ขวดน้ำมันหอมระเหยแบรนด์ยุโรป — ฉลากเรียบ ตัวอักษรเว้นระยะกว้าง สีเดียว
- กระดาษ letterpress หนาๆ มีสัมผัส

**คุณลักษณะที่ต้องรู้สึกได้:** สงบ / มีระยะห่าง / ประณีต / อบอุ่น / ไม่รีบเร่ง

**สิ่งที่ต้องหลีกเลี่ยงเด็ดขาด:**
- neon gradient แบบ Instagram ปี 2019
- ทองแวววาว เพชร มงกุฎ สัญลักษณ์ความรวย
- emoji ทุกชนิดใน UI
- คำโปรยแบบ hype (`UNLOCK YOUR POWER!!!`)
- การ์ดขอบมนจัด + เงาฟุ้งแบบ template ทั่วไป
- ภาพ stock ผู้หญิงนั่งสมาธิริมทะเล

## 3. Art direction

### 3.1 สี

ฐานเป็น warm neutral ทั้งหมด ใช้สีเน้นแบบ muted อย่างประหยัด

| บทบาท | ค่า | ใช้ตรงไหน |
|---|---|---|
| Canvas (light) | `#F7F4EF` alabaster | พื้นหลังหลักโหมดสว่าง |
| Canvas alt | `#EDE6DC` warm sand | การ์ด พื้นผิวรอง |
| Ink | `#1C1917` | ตัวอักษรหลักโหมดสว่าง |
| Canvas (dark) | `#191517` | พื้นหลังหลักโหมดมืด |
| Ink (dark) | `#F2EDE6` | ตัวอักษรหลักโหมดมืด |
| Accent — champagne | `#C2A57B` | เส้นคั่น ไอคอน active, **แบบด้าน ห้ามไล่เงาให้เงาวาว** |
| Accent — sage | `#9AAE9C` | หมวดหมู่สายสงบ |
| Accent — clay | `#C99C94` | หมวดหมู่สายความรัก/ตัวตน |
| Accent — deep teal | `#1F4B47` | หมวดหมู่สายพลัง/ขอบเขต |
| Accent — plum | `#5E4C63` | หมวดหมู่สายกลางคืน |

**กฎ:** หนึ่งหน้าจอใช้สีเน้นได้ไม่เกิน 1 สี ที่เหลือเป็น neutral ทั้งหมด

### 3.2 Gradient สำหรับ widget และการ์ด

ออกแบบ **8 ธีม** โดยแต่ละธีมต้องนุ่ม ไล่ระดับช้า ไม่มีขอบตัดชัด ค่าความสว่างระหว่างสองปลายห่างกันไม่เกิน 35% เพื่อให้ตัวอักษรอ่านออกทุกจุด

ชุดที่เสนอ (ปรับได้): Dawn / Mist / Linen / Dusk / Onyx / Sage Field / Clay / Deep Water

แต่ละธีมส่งมอบ: ค่าสี stop ทุกจุด, มุมของ gradient, สีตัวอักษรที่คู่กัน, และ **ค่า contrast ratio ที่วัดได้จริง**

### 3.3 ตัวอักษร — อ่านหัวข้อนี้ให้ละเอียดที่สุด

นี่คือจุดที่แอปหมวดนี้พังบ่อยที่สุดเมื่อทำภาษาไทย

- **ห้ามเลือกฟอนต์ที่ไม่มี glyph ภาษาไทย** ถ้าเลือก Cormorant หรือ Playfair แล้วใส่ข้อความไทย ระบบจะ fallback ไปฟอนต์เริ่มต้นทันที ความสวยหายหมด
- ฟอนต์ที่ใช้ได้จริงและได้ฟีล luxury: **Noto Serif Thai** (สำหรับ affirmation), **IBM Plex Sans Thai** หรือ **Anuphan** (สำหรับ UI)
- ใช้ฟอนต์ตระกูลเดียวกันทั้งไทยและอังกฤษ เพื่อให้ความหนาและความสูงของตัวอักษรเข้ากัน
- ทดสอบทุกดีไซน์ด้วยคำที่มีสระบนสระล่างซ้อนกัน: **"ปั๊ก" "ญื่" "ฟื้น" "ที่" "ผู้"** ถ้าวรรณยุกต์โดนตัดหรือชนบรรทัดบน แปลว่า line-height แน่นเกินไป
- `lineHeight` ของข้อความไทยต้องกว้างกว่าอังกฤษ ให้ตั้งอย่างน้อย **1.6 เท่า** ของ font size สำหรับ affirmation
- ภาษาไทยไม่มีเว้นวรรคระหว่างคำ ให้ระบุกฎการตัดบรรทัดและแสดงตัวอย่างข้อความยาว 3 บรรทัดในทุก mockup

**Type scale ที่ต้องการ:** Display (affirmation), Title, Body, Label, Caption — พร้อมค่า size / weight / line-height / letter-spacing ครบทุกระดับ

### 3.4 ระยะและรูปทรง

- Grid ฐาน 8dp
- **ที่ว่างคือสินค้า** ระยะขอบหน้าจอไม่น้อยกว่า 24dp การ์ด affirmation ให้ที่ว่างรอบข้อความอย่างน้อย 32dp
- มุมโค้ง: การ์ด 20dp / ปุ่ม 14dp / widget ปล่อยให้ระบบจัดการ
- เงา: ใช้ให้น้อยที่สุด ถ้าจำเป็นให้เป็นเงาฟุ้งกว้างและจางมาก แทนที่จะใช้เส้นขอบ

### 3.5 Motion

จังหวะต้องเหมือนลมหายใจ ไม่ใช่เหมือนแอปธนาคาร

- Transition หน้าจอ: 400–600ms, ease-in-out
- Gradient เคลื่อนบนหน้าหลัก: วนรอบละ 8–12 วินาที ช้าจนแทบไม่ทันสังเกต
- ปุ่มหายใจในโหมดสมาธิ: เข้า 4 วินาที ออก 6 วินาที
- ห้ามใช้ bounce หรือ spring ที่เด้งแรง

## 4. หน้าจอที่ต้องออกแบบ

### เฟส A — หัวใจของสินค้า
1. **Widget gallery** — หน้าที่โชว์ธีม widget ทั้งหมด นี่คือหน้าที่ขายของ
2. **Widget mockups** — 3 ขนาด (2×2, 4×2, 4×4) × 8 ธีม แสดงบนหน้าโฮมจริงที่มีวอลเปเปอร์หลากหลาย ทั้งภาพสว่างและภาพมืด
3. **Home / การ์ด affirmation** — เลื่อนแนวตั้งทีละใบเต็มจอ พร้อมปุ่ม บันทึก / แชร์ / เปลี่ยนธีม

### เฟส B — Funnel
4. **Onboarding** 5 หน้าจอ: welcome → คำถาม 5 ข้อ (เลือกตอบแบบการ์ด) → หน้ากำลังประมวลผล → หน้าผลลัพธ์ที่ personalize → paywall
5. **Paywall** — 3 แพ็ก (สัปดาห์ทดลองฟรี / ปี / ตลอดชีพ) แบบไม่กดดัน ไม่มีนาฬิกานับถอยหลังกระพริบ
6. **Notification** — ตัวอย่างหน้าตาการแจ้งเตือนบน lock screen

### เฟส C — ส่วนที่เหลือ
7. หน้าเลือกหมวดหมู่ (10 หมวด)
8. รายการที่บันทึกไว้
9. หน้าตั้งค่า (เวลาแจ้งเตือน / ธีม / ภาษา)
10. Empty state และ loading state
11. ชุด icon (เส้นบาง 1.5dp น้ำหนักเดียวกันทั้งชุด)

### เฟส D — การตลาด
12. **Play Store screenshot** 6 ภาพ — ภาพแรกต้องเป็น widget บนหน้าโฮมจริง ไม่ใช่หน้าจอในแอป
13. App icon (ทดสอบที่ 48dp ว่ายังอ่านออก)
14. Feature graphic 1024×500

## 5. ข้อจำกัดทางเทคนิคที่ต้องออกแบบให้อยู่ในกรอบ

**สำคัญที่สุด — widget ไม่ใช่ Compose**

Glance ทำงานบน RemoteViews ข้างใต้ แปลว่า widget **ไม่มี** blur, ไม่มีอนิเมชัน, ไม่มี canvas, ไม่มี gradient สด เราจะแก้ด้วยการ **วาด widget ทั้งใบเป็น bitmap** แล้วส่งเข้า Glance เป็นภาพเดียว

ผลที่ตามมาต่อการออกแบบ:
- widget ทุกธีมต้องเป็น **ภาพนิ่ง** ที่สวยในเฟรมเดียว ห้ามพึ่งพาการเคลื่อนไหว
- ทุกองค์ประกอบต้องอยู่ในภาพเดียว ไม่มี layer โปร่งใสซ้อนกับวอลเปเปอร์ผู้ใช้
- ระบุขนาด bitmap ที่ต้องวาดสำหรับแต่ละขนาด widget ให้ชัด
- ข้อความบน widget ต้องอ่านออกแม้ผู้ใช้ตั้งวอลเปเปอร์ที่มี noise สูง ให้ออกแบบพื้นหลังทึบพอ

**ข้อจำกัดอื่น:**
- `Modifier.blur()` ใช้ได้เฉพาะ Android 12+ ต้องออกแบบ fallback สำหรับเวอร์ชันต่ำกว่า
- AGSL shader ใช้ได้เฉพาะ Android 13+ อย่าให้ดีไซน์หลักพึ่งพาสิ่งนี้
- รองรับ dark mode และ dynamic color ของ Android 12+
- ปุ่มกดทุกจุดไม่เล็กกว่า 48×48dp
- Contrast ratio ข้อความหลักไม่ต่ำกว่า 4.5:1

## 6. สิ่งที่ต้องส่งมอบ

1. **Design tokens** เป็นตาราง: สี / typography / spacing / radius / elevation / motion duration — พร้อมชื่อ token ที่แปลงเป็น Compose theme ได้ตรงๆ
2. **Mockup รายหน้าจอ** ทั้งโหมดสว่างและมืด พร้อมข้อความไทยจริงไม่ใช่ lorem ipsum
3. **สเปก widget ทั้ง 8 ธีม** พร้อมค่าสี gradient stop และตำแหน่งข้อความเป็นตัวเลข
4. **หน้ารวม type specimen** โชว์ข้อความไทยที่มีวรรณยุกต์ซ้อนในทุกขนาด
5. หมายเหตุสำหรับนักพัฒนา: จุดไหนที่ต้องระวังเมื่อแปลงเป็น Compose

## 7. เกณฑ์ตัดสินว่างานสำเร็จ

- ถ่ายภาพหน้าจอมือถือที่มี widget นี้อยู่ แล้วโพสต์ลง TikTok ได้โดยไม่ต้องแต่งเพิ่ม
- คนที่เห็น widget บนมือถือเพื่อนแล้วถามว่า "แอปอะไร"
- ดูแล้วไม่รู้สึกว่าเป็น template ที่เห็นมาแล้วสิบครั้ง
- ข้อความภาษาไทยดูตั้งใจออกแบบ ไม่ใช่ดูเหมือนเอาดีไซน์อังกฤษมาแปะทับ

## 8. ลำดับงานที่ขอ

เริ่มจาก **เฟส A เท่านั้น** ส่งมาก่อน 3 อย่างนี้:

1. Design token ชุดเต็ม
2. Type specimen ภาษาไทย
3. Widget 4×2 จำนวน 3 ธีม แสดงบนวอลเปเปอร์ 3 แบบที่ต่างกัน

รีวิวเสร็จแล้วค่อยไปเฟสถัดไป
